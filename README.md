# Online Study Material Platform

I built this web-based study material platform to give students, teachers, and parents one simple place to find, share, and use educational resources. Users can search for PDFs, images, worksheets, notes, and previous question papers based on what they need for study or teaching.

The main idea behind this project was to create a useful learning resource website where a student can come to the platform, search for a required topic or material, and access resources that are useful for preparation. Teachers can also find or share educational content, while parents can use the available resources to support their children's studies. I focused on making the process of finding, uploading, and accessing educational content simple and user-friendly.

## Key Features

* Upload and share study materials
* Support for PDF and image-based resources
* Search functionality for finding study materials
* Access worksheets and previous question papers
* Share notes and other educational resources
* Organized educational content
* User-friendly interface
* Easy access to useful study resources

## Technology Used

* Django

## How It Works

Students, teachers, and parents can access the platform and search for educational resources based on their requirements. A student can search for a worksheet, previous question paper, PDF, image, or other useful study material and choose the resource that best matches their needs.

Users can also upload and share useful study materials with the learning community. The search functionality makes it easier to find specific resources without going through the entire collection manually, helping users save time and focus more on learning.

## Installation

Clone the repository:

git clone <your-repository-url>

cd <project-folder>

Create a virtual environment:

python -m venv venv

Activate the virtual environment.

Windows:

venv\Scripts\activate

Linux/macOS:

source venv/bin/activate

Install the required packages:

pip install -r requirements.txt

Run database migrations:

python manage.py migrate

Start the Django development server:

python manage.py runserver

Open the project in your browser:

http://127.0.0.1:8000/
